# Shapes

A **shape** is the fixed skeleton of one kind of document: every document of that kind has the same parts in the same
order. This is the shape particular to handing work from one agent to another. The general ones (note, folder README,
report, commit message) and the reasons for shapes are in
[reader-ergonomics](https://github.com/Tewf/reader-ergonomics/blob/4f99372093729dacf982e9174e94f6b8793c513d/shapes/README.md).

## Contents

| Shape | For |
|---|---|
| [exchange.md](exchange.md) | one piece of work handed to another agent and returned: a task file with Task, Decided, To find and Checks, a result file kept as it came, and the verdict written elsewhere; its worked example is the brief test's own task |

## Choosing a shape

- One document, one shape: a text that needs two shapes is two documents.
- Each part of a shape cites the finding that justifies it, with that evidence's grade; a part with no evidence says
  "convention, untested".
