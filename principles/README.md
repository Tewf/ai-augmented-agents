# Principles

The principles particular to handing work from one agent to another, in two groups. Each follows the format of the
reader-ergonomics principles; a principle that standard already holds is linked, never restated here. The shape they
apply to is the [exchange](../shapes/exchange.md).

| Group | What it covers |
|---|---|
| [Brief: what a task file holds](brief/README.md) | the task file the lead writes: its checks, the reason for handing over, and what happens on failure |
| [Result: what comes back](result/README.md) | the result file and what the lead does with it |
