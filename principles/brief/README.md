# Brief: what a task file holds

What the lead writes before work leaves for another agent, so that the worker can be right and the lead can tell. The
shape is the [exchange](../../shapes/exchange.md), and this group is its task file.

| Principle | Claim |
|---|---|
| [List the checks](list-the-checks.md) | the task file lists the checks that will judge the result, as commands |
| [Say why it is handed over](say-why-handed-over.md) | the task file says why this work leaves the lead, and defaults to doing it alone |
| [Escalate on a failed check](escalate-on-a-failed-check.md) | the task file says what happens when the check fails, usually a stronger worker |
