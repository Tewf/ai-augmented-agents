# Result: what comes back

What the lead does with the file a worker returns: run the checks at the lead, and keep the result as it came. The shape is
the [exchange](../../shapes/exchange.md), and this group is its result file.

| Principle | Claim |
|---|---|
| [Run the checks at the lead](run-the-checks-at-the-lead.md) | the lead runs the listed checks on every result before using it |
| [Keep the result untouched](keep-the-result-untouched.md) | the result file stays as the worker wrote it, and the verdict is written in another file |
